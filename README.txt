CURSED GROVE v1.6.0 - phone install

1. Put the files in this folder on any HTTPS web host (GitHub Pages, Netlify Drop, Cloudflare Pages, your own site).
2. Open the page on your phone:
   - Android (Chrome): menu > Install app (or Add to Home screen).
   - iPhone (Safari): Share > Add to Home Screen.
3. It then opens full screen like a normal app and works offline. Turn the phone sideways to play.

Your saves live on the device. To move progress from another device use Journal > Guide > Export save, then Import save.
